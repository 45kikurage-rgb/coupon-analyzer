# coupon-analyzer

独立した「クーポン判定」PWAです。画面とAPIを別リポジトリに分離し、Cloudflare Service Bindingで `coupon-analyzer-api` を利用します。

- 安定解析 / 高速解析
- 最大2,000URL、重複URL除外、100件ずつ分割解析、API側で最大3回の解析試行
- 2,000件超は解析前に通知。通信失敗・応答欠落も判定不能として全件を結果に残し、後続を解析
- 共通APIの1リクエスト上限（500件）・同時実行数・判定契約は変更しません
- セブン・ファミマ・プチギフト（ローソン）の整形済みスクリーンショットとZIP
- 商品名・容量・期限・利用済み・Giftee残高の表示
- SBギフト・スターバックスを含む解析API対応URLを画面から判定
- 手動修正と解除（このサイトだけで操作）

クーポンキャプチャーのサイトやAPIには依存しません。

## 2026-11-08 プチギフトの撮影対応

`coupon.petit.gift/coupons/detail` のローソンクーポンを撮影できます。商品名・店舗利用期限・公式バーコード画像を読み取り、画像に含まれる18桁（先頭0）と券面の17桁が一致する場合だけ画像を生成します。バーコードは店舗名の下に配置し、既存のPNG保存・重複判定・ZIPを使用します。解析だけでなく撮影も対応します。

対応店舗・期限・番号を確認できないページは画像を生成せず、引換・使用操作は行いません。元URLの認証パラメータは画像とエラー応答に載せません。既存のDB・認証・公開URL・サービスバインディングは変更しません。

検証：3リポジトリ合計78テスト成功、2 Workerのdry-runビルド成功。実URLのHTMLで商品名・店舗利用期限・バーコード照合を確認。本番反映と公開後撮影は別途確認します。
