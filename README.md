# coupon-analyzer

独立した「クーポン判定」PWAです。画面とAPIを別リポジトリに分離し、Cloudflare Service Bindingで `coupon-analyzer-api` を利用します。

- 安定解析 / 高速解析
- 最大2000URL、重複URL除外、100件ずつ分割解析、最大3回再解析
- セブン・ファミマの整形済みスクリーンショットとZIP
- 商品名・容量・期限・利用済み・Giftee残高の表示
- SBギフト・スターバックスを含む解析API対応URLを画面から判定
- 手動修正と解除（このサイトだけで操作）

クーポンキャプチャーのサイトやAPIには依存しません。

- QUOカードPayの残高（円）と残高あり／なし／確認不可を表示
- 解析結果の各行に「URLを開く」。取得失敗した行も元URLを保持
- 2000件超は分割を案内し、黙って切り捨てない
- QUO実URLの取得は作業環境で403のため未検証。HTML残高抽出の合成試験と実URL受入を区別する
